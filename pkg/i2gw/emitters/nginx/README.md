# NGINX / NGINX Gateway Fabric Emitter

This emitter takes the intermediate representation (IR) generated by a provider and outputs the Gateway API resources, including any of [NGINX Gateway Fabric's](https://github.com/nginx/nginx-gateway-fabric) policies and CRDs.

**Note**: This emitter is specifically for NGINX Gateway Fabric, to allow the use of NGF specific policies and CRDs. Some annotation mappings may only require the use of the standard emitter, when only standard Gateway API resources are required. 

## Usage

```bash
# Convert NGINX Ingress Controller resources from cluster
ingress2gateway print --providers=nginx --emitter=nginx

# Convert from file
ingress2gateway print --providers=nginx --emitter=nginx --input-file=nginx-ingress.yaml

# Convert from file and write to a specific file
ingress2gateway print --providers=nginx --emitter=nginx --input-file=nginx-ingress.yaml > nginx-gateway.yaml
```
## Contributing

When adding support for more of NGINX Gateway Fabric's policies:

1. Add the emit function to `buffer.go`
2. Create the policy inside `builder.go`
3. Call the buffer function in `ToNginxResources` inside the nginx emitter `nginx.go`
4. Add relevant tests to `nginx_test.go`
